Com base na Constitution e na Specification, elabore um plano completo de desenvolvimento, mas enxuto e objetivo.

Tecnologias obrigatórias:

• React Native
• JavaScript
• SQLite
• API REST
• Arquitetura offline-first

O plano deve definir:

• arquitetura geral do projeto;
• organização das pastas;
• módulos principais;
• separação entre camadas;
• estratégia de persistência;
• estratégia de notificações;
• estratégia para geração de relatórios;
• estratégia de exportação JSON;
• estratégia de testes;
• bibliotecas sugeridas;
• decisões técnicas justificadas;
• cronograma sugerido de implementação.
