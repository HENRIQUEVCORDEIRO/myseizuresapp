## Final gaps and recommended follow-up

1. Extend the chronological event contract, use case, presentation model, and tests to include
   treatment reminders and adherence confirmations for FR-006.
2. Cache the minimum validated session identity needed for safe offline route restoration, define its
   expiry/revalidation policy, and ensure patient report authorization can resolve self-access
   without the API for FR-013.
3. Run the manual-device checklist in [validation.md](validation.md#manual-follow-up-checklist),
   especially notification delivery/tap, native sharing, screen reader, and large-font behavior.
4. Conduct representative-user timing studies before claiming SC-001, SC-002, or SC-003.

These items are findings of the T055 review. They are not silently added to the current task scope;
use `speckit-converge` to append implementation work to `tasks.md` if the project should close the
identified gaps.
