# D6 — Home do profissional com pacientes autorizados

> **Data original:** 27/10/2026 (terça) · **Execução:** 30/10/2026
> **Entrega:** lista de pacientes com acesso ativo na home do profissional, sem digitar ID, com
> abertura direta do relatório e remoção imediata após revogação

---

## 1. O que foi entregue

### 1.1 Lista de pacientes autorizados

A home do profissional deixou de ser uma tela morta com apenas “Sair”. Agora ela consulta os
compartilhamentos ativos do profissional autenticado e mostra um card por paciente:

- “Paciente 1”, “Paciente 2”, etc.;
- status “Acesso ativo”;
- data de concessão;
- toque no card abre o relatório semanal do paciente.

O profissional não digita mais identificador numérico no fluxo principal. A rota antiga
`/(professional)/patients` passou a ser um alias da home, mantendo compatibilidade com deep links.

### 1.2 API — endpoint do profissional

Novo endpoint:

```text
GET /professionals/me/patients
```

Regras:

- exige token de profissional (`MEDIC_CARETAKER`);
- o `medicCaretakerId` vem do token, nunca da URL;
- retorna apenas grants ativos do próprio profissional;
- paciente tentando acessar recebe `403 FORBIDDEN`;
- grants revogados desaparecem da resposta.

O repositório em memória ganhou `listActiveByProfessional`, com ordenação por data de concessão
mais recente.

### 1.3 Mobile — caso de uso e cliente

- `AccessGrantRepositoryPort` passou a exigir `listAuthorizedPatients`.
- `AccessGrantClient` chama `GET /professionals/me/patients`.
- Novo caso de uso `ListAuthorizedPatients`, usando apenas o token da sessão.
- `container.js` expõe `listAuthorizedPatients` para a home profissional.

### 1.4 UI e estados

A home profissional implementa os cinco estados:

| Estado | Conteúdo |
|---|---|
| Loading | “Carregando pacientes” |
| Empty | “Nenhum paciente compartilhou dados” + orientação para conceder acesso |
| Error | “Pacientes indisponíveis” + “Tentar novamente” |
| Success | lista de cards com “Acesso ativo” e data de concessão |
| Ação | “Atualizar” e “Sair” |

A lista é recarregada quando a tela volta ao foco, cobrindo o retorno do relatório. O botão
“Atualizar” permite nova consulta manual.
